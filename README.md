## Run locally in VS Code
Use VS Code Live Server, or run:

```bash
python -m http.server 5500
```

Then open:

http://localhost:5500

Do not open the HTML file directly if you want to test the service worker; use localhost.

## Deploy to Cloudflare Pages
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Test locally.
4. Push the complete folder to GitHub.
5. In Cloudflare Pages, create a project and connect the GitHub repository.
6. Framework preset: None / blank.
7. Build command: leave empty.
8. Build output directory: repository root.
9. Deploy.
